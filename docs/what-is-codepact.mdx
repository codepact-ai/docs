## The Problem

GitHub's organization settings apply the same rules to **all repositories** — but your teams don't have identical needs.

| Team | Need | Problem |
|---|---|---|
| Platform | Strict CI/CD gates, 2+ approvals | ✅ Works fine |
| Data Science | Fast iteration, experiment flexibility | ❌ Blocked by platform rules |
| Security | Signed commits, 3+ approvals | ❌ Rules too lenient |
| Open Source | Community-friendly workflow | ❌ Internal rules don't fit |

## The Solution: Layered Governance

CodePact AI introduces **Pacts** — composable governance policies that stack on top of an org-wide baseline. Every layer can only add stricter requirements, never weaken them.

```
Org Baseline  +  Team Pact  +  Profile  +  Template  =  Effective Policy
```

→ Security teams set a floor that **cannot be undermined**.
→ Teams get exactly the rules they need without affecting others.

## How It Works

1. **Install the GitHub App** on your organization
2. **Connect your org** in the CodePact dashboard
3. **Define your Org Baseline** — the minimum policy for all repos
4. **Create Team Pacts** — additional rules per team
5. **Enable enforcement** — CodePact auto-remediates drift in real time
