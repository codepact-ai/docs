## Base URL

```
https://codepact.ai/api
```

## Authentication

All API requests require a valid session token obtained via GitHub OAuth or a CodePact API token.

```bash
Authorization: Bearer <your-token>
```

<Note>
A formal OpenAPI spec (`openapi.yaml`) is in progress. The interactive API explorer will be available here once published.
</Note>

## Versioning

The API is versioned. The current stable version is `v1`. Breaking changes are always introduced in a new version with a deprecation notice.

```
https://codepact.ai/api/v1/...
```
