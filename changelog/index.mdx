## March 2026

### Bug Fixes

- **Onboarding install link corrected**: The "Install CodePact App" button in the onboarding flow now correctly links to `github.com/apps/codepact-ai/installations/select_target`. The previous link used an incorrect app slug and deprecated endpoint path.
- **Multi-region webhook reliability**: Resolved a connectivity issue where webhooks were not being processed after installation. The NATS JetStream pub/sub chain is now fully operational across all event types (lifecycle, repository, team, security, push).

---

## February 2026


### AI Policy Assistant
The AI chat assistant is now available in the Pact Editor. Ask questions like "What repos are missing branch protection?" or "Which team has the strictest settings?" and get instant answers.

### Shared Compliance Reports
Generate a signed, public-shareable link to any compliance snapshot. Perfect for sharing audit evidence with stakeholders who don't have a CodePact account.

### Webhook Event Processing (Dapr)
Webhook processing is now fully asynchronous via Dapr + NATS pub/sub, improving reliability and enabling horizontal scaling.
